# HelpingHands – Social Development Events Platform

HelpingHands is a community-driven social development platform where people can discover events, participate in social activities, and contribute to making their communities better.

Add your deployed website URL here.

## Features

- User authentication with Email/Password and Google Login.
- Browse upcoming social development events.
- Create, update, and delete personal events.
- Join events and manage joined events.
- Protected routes with JWT authentication.
- Responsive design for mobile, tablet, and desktop.
- Light and Dark theme support.
- MongoDB database integration.

## Technologies Used

- Next.js
- TypeScript
- Tailwind CSS
- Express.js
- MongoDB
- Better Auth
- JWT
