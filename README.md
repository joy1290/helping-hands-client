# HelpingHands – Social Development Events Platform

HelpingHands is a social development events platform where people can discover upcoming events, create events, and participate in community activities. The platform encourages people to connect and work together to make a positive impact on society.

## 🌐 Live Website

[Visit HelpingHands](https://helping-hands-client-five.vercel.app/)

## 📂 Repositories

- **Client Repository:** https://github.com/joy1290/helping-hands-client
- **Server Repository:** https://github.com/joy1290/helping-hands-server

## ✨ Key Features

- **User Authentication:** Register and log in securely using email and password or Google authentication.
- **Upcoming Events:** Browse upcoming social development events.
- **Create Events:** Logged-in users can create events by providing event details.
- **Event Details:** View complete information about individual events.
- **Join Events:** Authenticated users can join events and participate in community activities.
- **Joined Events:** View and track events you have joined.
- **Manage Events:** Event creators can update or delete their own events.
- **User Profile:** Access profile information and account options.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Protected Routes:** Private pages and API operations require authentication.

## ⚙️ Installation and Setup

### 1. Clone the repository


git clone https://github.com/joy1290/helping-hands-client.git


### 2. Navigate to the project directory


cd helping-hands-client


### 3. Install dependencies


npm install


### 4. Configure environment variables

Create a `.env.local` file in the root directory:


NEXT_PUBLIC_API_URL=http://localhost:5000
NEXT_PUBLIC_BETTER_AUTH_URL=http://localhost:5000


Use the appropriate deployed server URL when connecting to the production backend.

### 5. Run the development server


npm run dev


Open [http://localhost:3000](http://localhost:3000) in your browser.
